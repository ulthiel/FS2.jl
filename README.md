# FS2.jl

FS2.jl contains Julia/OSCAR code for computational investigations of a character-theoretic problem posed by Gabriel Navarro in [1, Problem 7.3]: if $\chi$ is an irreducible character of a finite group and $\chi$ has odd degree or is $2$-rational, is its character field $\mathbb{Q}(\chi)$ generated by a single character value?

We call this the **FS₂ problem**, where **FS** stands for character *field* generated by a *single* value and the subscript $2$ indicates the $2$-local nature of Navarro's question.

The package provides functionality for testing the FS₂ property for individual characters and character tables, together with tools for systematic searches in the GAP Character Table Library and the Small Groups Library. It also contains code used for the computational investigations in [2].

The complete computational output accompanying [2] is included in the
[`results`](results) directory. See [`results/README.md`](results/README.md)
for the scope, format, provenance, and summary of these data.

## Installation

FS2.jl is not registered in the Julia General registry. Install it directly from GitHub using Julia's package manager:

```julia
using Pkg
Pkg.add(url="https://github.com/ulthiel/FS2.jl", rev="v1.0.0")
```

After installation, load the package with:

```julia
using FS2
```

## Usage

The main function is `is_fs2_with_data`, which tests the FS₂ property for a character table and returns both the result and data for any failures found. For example:

```julia
using Oscar, FS2

T = character_table(:Symmetric, 5)
is_fs2_with_data(T; q=2)
```

Use `is_fs(χ)` to test a single character for field generation by one value.
`is_fs(T)` and `is_fs(G)` test every irreducible character of a character
table or finite group, without the degree or rationality restriction of FS₂.

To test whether a character's conductor is attained by a single value, use
`is_cs(χ)`. For a character table or finite group, `is_cs` tests every
irreducible character, without a degree or rationality restriction:

```julia
G = symmetric_group(5)
is_cs(G)                    # true
is_cs(character_table(G))    # true
```

Use `is_fs_with_data(T; findall=true)` or `is_cs_with_data(T; findall=true)`
to return `(result, failures)` with diagnostics for every failing Galois
orbit. Both also accept a finite group in place of `T`. By default they
stop after the first failure. They support the same `table_label`,
`findings_log_file`, `scan_log_file`, and `metadata` logging keywords as
`is_fs2_with_data`, but have no `q` parameter or character restrictions.
For a single character, `is_cs_with_data(χ)` returns the result together
with `char_conductor` and `max_value_conductor`.

To scan the GAP Character Table Library with `q=2` and write the results to a log directory:

```julia
scan_ctbllib_fs2(q=2, log_dir="results")
```

To scan a range of orders in the GAP Small Groups Library:

```julia
scan_smallgroups_fs2(1:1000; q=2, log_dir="results")
```

To scan the Small Groups Library for the conductor-attainment property, use:

```julia
scan_smallgroups_cs(1:1000; log_dir="results")
```

This scan skips prime-power orders because CS holds for nilpotent groups.
