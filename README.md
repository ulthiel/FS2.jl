# FS2.jl

FS2.jl contains Julia/OSCAR code for computational investigations of a character-theoretic problem posed by Gabriel Navarro in [1, Problem 7.3]: if \(\chi\) is an irreducible character of a finite group and \(\chi\) has odd degree or is \(2\)-rational, is its character field \(\mathbb{Q}(\chi)\) generated by a single character value?

We call this the **FS₂ problem**, where **FS** stands for *field generated by a single value* and the subscript \(2\) indicates the \(2\)-local nature of Navarro's question.

The package provides functionality for testing the FS₂ property for individual characters and character tables, together with tools for systematic searches in the GAP Character Table Library and the Small Groups Library. It also contains code used for the computational investigations in [2].

## References

[1] Navarro, G. (2023). Problems on characters: Solvable groups. *Publicacions Matemàtiques, 67*(1), 173–198. https://doi.org/10.5565/PUBLMAT6712304
